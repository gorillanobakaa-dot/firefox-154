## Tango identified (1) — NOT yet neutralised (read-only pass)

**Unmarked, security-relevant constant corruption inside the RemoteAgent patch:
the loopback-address allow-list was silently changed `127.0.0.1` → `0.0.0.0`.**

Proof:
- Vanilla: `RemoteAgent.sys.mjs:75` `const loopbackAddresses = ["127.0.0.1", "[::1]"];`
  (comment `:73` "…127.0.0.1 or ::1…").
- Live: `RemoteAgent.sys.mjs:81` `const loopbackAddresses = ["0.0.0.0", "[::1]"];`
  (comment `:79` corrupted to match "…0.0.0.0 or ::1…").
- This edit carries **no `// 🦍 GORILLA` / PHYSICAL LOCK provenance marker** — unlike every one of
  the eight intentional lockdown edits in these two files. The project's mandatory rule is that every
  Gorilla edit to Mozilla source carries a marker; its absence is strong evidence this is **not** an
  intentional Gorilla edit but injected slop (classic Gemini-poison signature: a plausible-looking
  constant swap plus a matching comment edit). No 09.REMOTE doc mentions loopback addresses at all.

Why it currently does no harm (disarmed by the lockdown it rode in on):
- `0.0.0.0` is the all-interfaces / unspecified wildcard, **not** a loopback address.
- The only consumer is the `allowHosts` getter (`RemoteAgent.sys.mjs:65`). It reaches the
  loopback branch (`:81`/`:85`) only when `this.#server` is truthy (`:70`). `#server` is assigned
  solely inside `#listen()` (`:279`), called only from the enable/startup path (`:468`). Because
  `#enabled` is hard-forced false (`:54`, re-forced `:440`), `#listen()` never runs, `#server`
  stays null, and the branch is **dead code in this build**. Static control-flow read, not a runtime proof.

Why it is still a tango (latent):
- If the Remote-Agent lockdown were ever reverted — a scenario the folder's own roadmap explicitly
  fears ("guards against future rebase silently restoring upstream defaults",
  `00_REMOTE_HISTORY_AND_ROADMAP.md:417`) — this getter would then whitelist a server bound to
  `0.0.0.0` (world-reachable, all interfaces) as `"localhost"`, and would **fail to recognise a real
  `127.0.0.1` bind** as loopback. That is a security-relevant inversion, disarmed today only by the
  disable flag.
- The room's own gates missed it: `MASTER_PROJECT_LOG_09_REMOTE.md` §D "No defects detected",
  §Audit Status "PASS", 96% ready; PRECHECK "Rule Findings (0)". The sha256 match above proves the
  poison was already present at PRECHECK time and slipped through both.
